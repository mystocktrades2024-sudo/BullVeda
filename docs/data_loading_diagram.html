2 · The trick — one bulk trip, not 4,800
1 call → whole market

EODHD's bulk endpoint returns yesterday's price for every US stock in one request = 100 credits for ~4,800 names. dumb way: 4,800 calls = 4,800 credits
Listing + pricing the whole universe ≈ 150 of 100,000 daily credits. And the Finviz Elite export API is a second bulk lever — one CSV pull returns ownership/short/float/SMA/PEG for the whole screener, off EODHD's meter entirely. The cost is never the list — it's the deep detail per stock.

E · Can Finviz replace EODHD? — No. Bars are the wall.
What EODHD doesFinviz replace?
Daily / weekly / monthly price BARS (history)❌ No — Finviz has no bar-history export, only a live snapshot
Fundamentals (margins / ROE / growth / valuation)✅ Yes — bulk, cheap
Ownership / short / float✅ Yes
Earnings dates✅ Yes (backfill)
Candidate screening (movers / gaps / new highs)✅ Yes — better, server-side
News articles⚠️ Partial
Point-in-time fundamentals (backtests)❌ No — live snapshot = look-ahead risk
Why bars are the wall: without price-bar history you can't build charts, structural targets (T1/T2/T3), SMC, Elliott Wave, backtests, or any indicator computed from price (RSI/MACD/ATR). That's the entire technical backbone — and it comes only from EODHD (+ Schwab 4H + local archive).
Takeaway: Finviz + EODHD, not Finviz instead of EODHD. Finviz offloads the expensive half — fundamentals (@10/ticker) + screening — so EODHD spend can drop ~50–70%. But EODHD stays as the price-bar backbone everything technical is built on. You swap out the costly fundamentals layer, not the data spine.

🧭 Regime is the meta-strategy (principle 18: "regime detection IS the strategy"). It decides which sleeves may fire, the BUY score floor, and the max position size. Computed in data_fetcher.get_market_regime() on the last completed daily bar — never intraday.
A · The 4 inputs
SignalWhatSource
TrendSPY & QQQ vs their EMA50 / EMA200 (above = risk-on, below = risk-off)EODHD daily bars
VolatilityVIX level — the fear gauge (low = calm, >35 = panic)EODHD $VIX
Breadth% of universe above its 50-day MA — participation (high = healthy, <20% = washout)computed from universe
Macro (context)HYG · UUP · GLD · BTC/ETH — risk appetite cross-checkEODHD
Degraded inputs are tracked explicitly: if VIX or breadth is missing, the engine records it rather than silently defaulting (VIX→20, breadth→50) — because a silent default would mask a data outage as a plausible "risk-on choppy" exactly when regime matters most.

C · Hysteresis — the anti-whipsaw buffer
Why: a regime that flips on a single noisy close would whipsaw sizing every day. So a flip requires an overshoot + confirmation, not just crossing the line.
To flip…Requires
Risk-on → risk-off (VIX)VIX must push above 22 to enter risk-off, but fall below 18 to return (gap buffer)
Bull ↔ bear (breadth)breadth > 53% to turn bullish, < 47% to turn bearish (dead-band in between)
Into risk-off (trend)consecutive closes below EMA50 (not a single touch) — risk_off_consecutive_closes

E · Data discipline
Anchored to the daily bar. The official regime is computed on the last completed daily bar (EODHD) — it does not move intraday. The /api/regime/live overlay (Schwab SPY/QQQ/$VIX) is display-only: it shows the live tape under the regime tile but never recomputes or flips the official regime. Why: intraday flips would whipsaw sizing, and breadth (% above 50DMA) can't be computed live — so a "live regime" would be half-blind. Regime is the one thing we compute slowly and deliberately, by design.
