Decision Waterfall (make_decision)

  1. Gate failure → AVOID (earnings blackout, extended >1.5 ATR above EMA21, liquidity, etc.)
  2. Entry quality: EXTENDED / MISSED → always WATCH (chase prevention)
  3. Setup exclusion: "52wk Breakout" → WATCH in bull (backtest-driven; too blunt)
  4. Bear path (SHORT): needs bear regime + VIX ≥ 25 + bear_score ≥ 16 + RR ≥ 3 + no squeeze
  5. Long path: score ≥ buy_min (68 bull / 70 neutral / 75 bear) AND RR ≥ 3 AND RS ≥ 75 AND weekly EMA bull AND has catalyst (or score ≥ buy_min+15)
  6. Overlays: sector cap (2 BUYs/sector), correlation >0.80 filter, drawdown kill switch (-8%), consecutive-loss circuit breaker, VIX tighten mode (+10 score bar)

2. What's Genuinely Good

  1. Backtest-grounded thresholds. Didn't guess 78/80 — tested it. 85.7% WR came from excluding 52wk Breakout (53% WR setup). Disciplined.
  2. Multi-regime design (risk_on_trending → panic) with position-sizing multipliers. max_size_pct: 0 for panic = most retail systems don't have a stop-trading mode.
  3. Setup family → exit rules mapping (Impulse Catalyst gets tighter trail, Breakout Expansion gets looser). Pro-level.
  4. VIX + breadth hysteresis prevents whipsaw losses.
  5. Entry quality tiers (FRESH / PULLBACK / VALID / EXTENDED / MISSED). EXTENDED → WATCH is the single biggest edge vs. retail systems.
  6. Catalyst gate: no catalyst → need score + 15. Prevents momentum-only BUYs with no "why now."
  7. Portfolio correlation gate (>0.80 = reject) stops accidentally buying 4 correlated tech names.
  8. Short setup is appropriately hard. Shorts are graveyards for retail; defaults reflect that.
  9. Conviction-tiered position sizing (85+ = 10%, 75+ = 7.5%, 65+ = 5%).

3. What Needs Improvement

1. Over-fit risk on the 85.7% WR number. 1-year S&P 500 backtest in a specific regime = one market cycle. With WR that high + PF 7.13, likely only 20-40 trades — statistically weak. Needs walk-forward + 2022 bear test before trust.
2. Scoring components sum > 100. 35+20+20+15+15+15+10+10 = 140. Hidden normalization obscures true component weights.
3. Threshold drift between config sections. decisions.buy_min_score: 65, regime_thresholds.bull.buy_min_score: 68, regime4_thresholds.risk_on_trending: 65, memory says "78 locked." Four sources of truth = bugs waiting.
4. 52wk Breakout blanket-excluded is too blunt. VCP-style elite leaders (Minervini/O'Neil playbook) get thrown out with the sloppy breakouts. See dedicated section below.
5. Short logic math is broken. bear_score ≥ 16/15 mathematically requires Zacks-sell +3 bonus — effectively making shorts Zacks-dependent. No short-interest or cost-to-borrow check — squeeze risk.
6. Correlation gate uses price correlation, not sector/factor. Two semis can be 0.75 correlated but blow up together on NVDA earnings miss. Need industry cap or factor overlay.
7. VIX tighten adds +10 to BUY bar but doesn't reduce position size. Currently separate paths. Should be unified so VIX spike = stricter entries AND smaller size.
8. No slippage/commission in backtest. At $500 positions with $21 avg win, a $0.50 spread eats ~2% per trade. Real WR probably 75-78%, not 85.7%.
9. Micro-account sizing tight. 5 positions × 20% = 100% gross, no cash. 1% risk on $1,000 = $50 stop = 5% stop distance. Most swing stops are 6-8%. Drop to 4 × 15% OR accept 1.5% risk/trade.
10. API keys committed plaintext. Polygon, Finnhub, FMP, Finviz, Alpaca, Gmail app password — all in config.json. Rotate everything, move to env vars.

4. Biggest Quick Win — Conditional 52wk Breakout Filter

What's happening now

Any stock breaking out to a 52-week high is automatically demoted to WATCH. Even an elite leader (NVDA-style, RS 98, perfect volume, tight base, strong catalyst) is blocked from BUY.

# analysis.py ~line 5072
if _exclude_setups and setup_type in _exclude_setups and direction == "long":
    return {"verdict": "WATCH", "reason": f"{setup_type} excluded..."}

Why that's too blunt — "52wk Breakout" is actually two setups

TypeCharacteristicsWR
Low-quality (majority)Weak RS (60-75), sloppy base, low volume~45-55%
Elite VCP-style (minority)RS 90+, tight contraction base, rising volume, sector leader70-85%

The Minervini / O'Neil / Weinstein playbook is literally "buy elite leaders breaking out from tight bases." The highest-EV setup in swing trading — being thrown out to avoid the losers.

Proposed conditional logic

if setup_type == "52wk Breakout" and direction == "long":
    is_elite_breakout = (
        rs_rank >= 90
        and indicators.get("atr_contraction", False)
        and indicators.get("rvol", 0) >= 1.5
        and weekly_bull
        and has_catalyst
    )
    if not is_elite_breakout:
        return WATCH
    # else: fall through to normal BUY logic

Gates: RS ≥ 90 (top decile) · ATR contraction (VCP tightness) · RVOL ≥ 1.5 · weekly bull · real catalyst. All 5 true → BUY eligible. Any fail → WATCH.

10. What I Need From You (the Trader)

  1. Commit to mechanical execution. If you override signals, the system is expensive decoration.
  2. Log every manual override in DECISIONS.md with reason. After 90 days, audit: did overrides make or lose money? (Almost always lose.)
  3. Don't add features mid-test. If running 60-day paper eval, freeze config. Changes after day 30 invalidate the data.
  4. Trust the validation process. Backtest = hypothesis. Paper = experiment. Live = production. Don't skip steps.
  5. Size small until proven. Even post-go-live, first 3 months at 50% size (10%/position, not 20%). Double only after 20 live trades confirm.
Final perspective: You've already built something better than 95% of retail trading systems. The design is sound. What's missing is validation rigor, execution infrastructure, and feedback loops. The next 12 weeks aren't about inventing new strategies — they're about proving the existing one works and building the rails to run it without emotion. That's the gap between "interesting backtest" and "actual income."
