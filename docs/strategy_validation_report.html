The Plan

Problem. The signal scanner floods BUYs with two high-volume setups (Trend Continuation, Breakout Expansion) that carry no skill — they make money only from momentum-factor exposure and bleed in chop. The genuine alpha lives in three low-volume setups (VCP / 52-week Breakout / 10-Week Pullback). The mix dilutes — and now appears to erode — edge.

Objective. Quantify what's actually working, then shift the picking mix toward alpha and away from beta — validated, not tuned by feel.

Validation gates — a change ships only if ALL hold

▹Walk-forward aggregate PF ≥ 1.20 (retail floor) after the −0.20 survivorship/slippage haircut
▹Sharpe improves vs baseline AND max-drawdown does not worsen
▹The alpha setups' Wilson 95% lower bound stays positive at n ≥ 30
▹Consistent across folds — not one lucky window (principle 5 regime-conditioning, principle 20 no acting on noise)

API / quota budget

Backtesting is cheap here: OHLCV bars are cached to parquet (2,184 files on disk) and reused across every variant; only params change between A/B and walk-forward runs. EODHD usage today 30,013 / 100,000 (70K headroom). Whole effort ≈ a few hundred one-time calls — the real cost is wall-clock compute, not quota.

What changed vs the polluted read — and the real lever. Once WATCH is removed: (1) the aggregate BUY alpha is still significantly negative — the core problem is real; (2) Breakout Expansion is only mildly negative on actual BUYs (−0.34%, n.s.), not the −1.17% the WATCH-polluted data showed — so "quarantine BE" needs the A/B to justify, not a foregone kill; (3) the genuine alpha setups VCP / 52wk barely fire as BUYs (n<20) — only 10-Week Pullback survives (n=35, +11.5%). Phase 1 — Candidate config deltas pending · re-prioritised

ROOT CAUSE FOUND — why VCP / 52wk are stuck at WATCH. The entry_quality gate (decision_engine.py:630) demotes any signal whose entry is MISSED / EXTENDED / FRESH to WATCH. In our breakout signals, 410 of ~462 WATCH demotions are EXTENDED (205) or MISSED (205) — and a breakout buys strength, so it is EXTENDED/MISSED past its base by construction. The gate (built for pullback mechanics: buy near support) penalises the exact entry a breakout requires. Six catalyst sleeves (Momentum, Defensive, MeanRev, PEAD, Insider, ESP) already bypass this gate — but VCP Breakout, 52wk Breakout, and 10-Week Pullback do not. The gate's own code comments concede MISSED (PF 2.59) and EXTENDED (PF 1.33) are more profitable than the PULLBACK (PF 0.88) it prefers — i.e. it demotes the profitable entries. Mirrors feedback_entry_quality_inverted (MISSED PF 2.06 best, FRESH worst).

Two findings from Arm A. ⚠ Methodology check pending Arm B: the backtest selects trades by top-5/day by score, not by verdict — so the breakout-bypass (which flips verdict labels WATCH→BUY) may produce the same trade set in both arms → a null P&L difference. If Arm B ≈ Arm A, it confirms the bypass is a surfacing/executor-gating change (helps the user + the verdict-gated executor), not a backtest-P&L change — and the A/B instrument would be wrong for this delta.
