How to wire this into kairos.html

Every visual element above maps 1:1 to data we already serve — no new license, no new model. 4 hours of front-end work.

1 · Data we already have

  1. cache/ml_edge_predictions.json — already served at /v2/ml_edge_predictions.json and cached client-side as window.__mlEdgeCache (see kairos.html ~line 33550). Shape: predictions.{swing|position|invest}.{TICKER}.
  2. Per-ticker payload contains direction {p_up,p_chop,p_dn,edge}, magnitude {q10,q25,q50,q75,q90,skew}, hit_net {p_t1_first,p_stop_first,model_auc,model_n}, shap.dir_top[] and model_meta {trained_at, calibration_health}.
  3. cache/target_engine/{TICKER}_{MODE}.json — already has the entry/stop/T1/T2 + p_reach blend (analog · MC · bayes). Use T1/T2 as the magnet lines if you want explicit price targets in addition to the magnitude cone.

2 · Data → visual mapping

magnitude.q25 → q75→cone band on chart
magnitude.q50→centerline + "+X.X%" badge
magnitude.q10 / q90→faint outer cone (tail risk)
direction.edge→cone tint (green if >0)
hit_net.p_t1_first→confidence pill + sub-text
shap.dir_top[]→"Why" bars on right
horizon_days→cone extends N bars right of "now"
target_engine T1/T2→price-line markers inside cone

  1. Button — add a new tab pill next to existing chart tabs in the qovHeroChart header (search _qovExpandChart near line 26703). One <button onclick="_aiPredToggle()">✦ AI Prediction</button> styled with --copper.

  5. Verdict + SHAP cards — drop below the hero chart as a new tv-cell in the same TV-grid (rows 4–5 of the hero). Re-uses existing .tv-cell CSS.

4 · Pseudocode for cone projection

function renderAICone(chart, candleSeries, pred, lastBar) {
  const { q10, q25, q50, q75, q90 } = pred.magnitude;     // %
  const N = pred.horizon_days;                            // 5 / 21 / 63
  const p0 = lastBar.close;
  // Synthetic future timestamps — one bar apart
  const future = Array.from({ length: N }, (_, i) => ({
    time: lastBar.time + (i + 1) * 86400,
    q25: p0 * (1 + (q25 / 100) * ((i + 1) / N)),
    q50: p0 * (1 + (q50 / 100) * ((i + 1) / N)),
    q75: p0 * (1 + (q75 / 100) * ((i + 1) / N)),
  }));

  // q25→q75 band (semi-transparent fill)
  const bandUp = chart.addAreaSeries({ topColor: 'rgba(217,119,87,0.25)', bottomColor: 'rgba(217,119,87,0.05)', lineColor: 'transparent' });
  bandUp.setData(future.map(f => ({ time: f.time, value: f.q75 })));
  // ... q25 lower band same pattern with bottomColor as bg

  // q50 centerline
  const center = chart.addLineSeries({ color: '#d97757', lineWidth: 2, lineStyle: 2 /* dashed */ });
  center.setData(future.map(f => ({ time: f.time, value: f.q50 })));

  // T1/T2 horizontal markers (optional, from target_engine)
  candleSeries.createPriceLine({ price: pred.t1_price, color: '#4ade80', lineStyle: 1, title: `T1 ${pred.t1_p_reach}%` });
}
