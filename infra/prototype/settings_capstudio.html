CapStudio RBAC Matrix role × function permissions

⌂ Dashboard / Settings / CapStudio
What this is. One row per function (tab / sub-tab / action). One column per role. Check the cell to grant the role access; uncheck to revoke. Save to persist. Wildcard * grants always win — admin keeps full access regardless of cell state.
Function source. Functions come from data/capability_registry.json — edit that file to add new gateable functions, then re-run scripts/migrate_role_capabilities.py to seed defaults.
Module path is shown under each function so you can locate the actual code that the gate protects.
