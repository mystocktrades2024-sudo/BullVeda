# ML Edge sub-tab

## Module
`subtabs/ml_edge/ml_edge.js` — extracted via CapStudio modular loader (2026-05-15).
Redesigned 2026-05-16 to risk-redesign aesthetic (Bloomberg terminal: 2px corners,
JetBrains Mono, copper §-numbers, semantic gn/rd/am/info/violet).

## Sub-modules
- `rk_styles.js` — single source of truth for .rk-* CSS, scoped under `.rk-scope`
- `hero.js`      — Breadcrumb-less hero: banner + forecast cone + 3 head gauges + conviction matrix + foot ribbon
- `heads.js`     — §1 "3-Head Decomposition" (split-3 chart cards: Direction bars / Magnitude box-whisker / Hit-Net stacked)
- `cone.js`      — §3 "Drilldown" (split-1-2-1: direction tiles + skew + quantile + per-horizon | large cone with T1/T2/Stop/ER overlays | level-hit ladder + headline probs)
- `levels.js`    — §4 SHAP feature attribution (split-2 bullish/bearish drivers) + reconciliation note + footer

## Aesthetic
All output is wrapped in `<div class="rk-scope">` by `ml_edge.js`. The scope
defines the local color/font tokens (`--bg`, `--ink-*`, `--gn`, `--rd`, `--amb`,
`--info`, `--violet`, `--copper`, `--mono: JetBrains Mono`) so the styles don't
leak into other sub-tabs until those tabs are migrated. To promote globally,
move the `:root` block from `rk_styles.js` into `elite-detail.html` and drop
the `.rk-scope` selector prefix.

## Default roles
admin, trader, quant

## Loader path
`core/elite-detail-shell.js` — sets `window.renderMlEdge = module.render` after import.

## Data source
Fetches `./ml_edge_predictions.json` (sibling to `data.json`). Cached on
`window.__mlEdgeCache` after first load. Per-ticker payload looked up by symbol.

Predictions are generated by:
```
python3 -m ml.run_ml_edge
```
which reads `cache/last_bundle.json` and writes both `cache/ml_edge_predictions.json`
and `infra/prototype/ml_edge_predictions.json`. Daily integration: append to
`run_daily_scan.sh` after `swing_trade.py`.

## Model
3 heads trained by `ml/train.py` on `cache/picks_history.json` (n=832 trades):
- Direction (3-class P(up)/P(chop)/P(down)) — `sklearn.GradientBoostingClassifier` + isotonic
- Magnitude (q10/q25/q50/q75/q90)            — 5x `GradientBoostingRegressor(loss='quantile')`
- Hit-Net  (P(T1 before stop))                — `GradientBoostingClassifier` + isotonic

Walk-forward holdout = last 25%. Final production model refit on all rows after
metrics captured. Hit-Net only trains when n_decisive ≥ 50.

## Calibration report
`cache/ml/calibration_report.json` — read at inference time to populate the
sub-tab's model_meta block (calibration_health, trained_at, per-regime breakdown).

## Empty-state contract
1. Predictions file missing entirely  → user prompted to run the inference job
2. Ticker absent from cache          → "not in scan pool" message
3. Payload present, verdict=NEUTRAL  → render normally (low confidence)

## Imports allowed
- `core/shared.js`: getData, $, fmt, dollar, escapeHtml, etc.
- **Nothing else from sibling tab modules.**

## Capability registry
`data/capability_registry.json` → `sub_tabs.ml_edge`

## Forbidden
- Mutating shared state (DATA, T) outside the data-poll path
- Importing from sibling tab modules
- Auto-sizing or auto-trading from ML output — informational only per CLAUDE.md principle 1
