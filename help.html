⚡ Quick Start

💻 Run Manually

# Full daily scan cd "/Volumes/MyMacDisk/Claude Skills/SwingTrade" python3 swing_trade.py # Deep dive on any single ticker python3 swing_trade.py deep NVDA # View performance history python3 swing_trade.py history

⏱ Automatic Daily Refresh

A macOS LaunchAgent runs the scan automatically every weekday at 4:47 PM (after market close). The dashboard opens in your browser automatically on success.

# Check it's running launchctl list | grep swingtrade # Run it right now manually launchctl start com.swingtrade.daily # View today's log cat SwingTrade/cache/logs/scan_$(date +%Y-%m-%d).log
💡 If your Mac is asleep at 4:47 PM, the scan runs as soon as it wakes up.

⚖ Decision Rules
VerdictConditionAction
BUY Score ≥ 75 AND R:R ≥ 3:1 Enter position — size 5–10% of portfolio
WATCH Score 55–74 or R:R < 3:1 Monitor — wait for setup to mature
AVOID Score < 55 or gate failed Skip — weak structure or blackout
KILLED Pre-trade gate hard failure Earnings ≤5 days, volume <$10M — always excluded
⚠ In a bear market regime (SPY below 50-EMA), the BUY threshold rises to 80 and R:R requirement stays at 3:1.

🔍 Detail Panel (click any stock)

Click any ticker card or table row to open the side panel. It has 4 tabs:

TabContents
OverviewPillar score rings, gate status, full trade plan (entry/stop/targets), bull/base/bear cases, position sizing grid
SignalsEvery sub-signal with its raw value, score bar, and plain-English explanation. Elliott Wave analysis with Fibonacci levels.
AnalystFull analyst consensus (25–45 analysts), price target, recent upgrades/downgrades, TradingView rating breakdown
NewsStockTwits social sentiment gauge + recent posts, latest news headlines, insider activity, earnings calendar
↔ Drag the left edge of the panel to resize it. Click ↔ to maximize/restore full screen.
🔍 Any-Ticker Search

The search box in the header lets you look up any ticker:

  • In today's scan — opens the full detail panel instantly with score, signals, chart, analyst data
  • Not in scan — shows the command to run a standalone deep-dive
python3 swing_trade.py deep TICKER

The deep-dive generates a single-ticker HTML dashboard with the full 4-pillar analysis.

🔧 Troubleshooting
ProblemFix
Zacks #1 shows 0 tickersCheck config/zacks_credentials.json — login may have expired; run manually to see Selenium output
Low market data fill rate (<90%)Install tvDatafeed: pip install tvDatafeed — enables Layer 3 fallback
Dashboard not auto-openingCheck cache/logs/scan_YYYY-MM-DD.log for errors; verify LaunchAgent is loaded with launchctl list | grep swingtrade
Analyst count shows only 5–12This should be fixed — data now comes from Yahoo quoteSummary API. If still low, the ticker may genuinely have few analysts.
StockTwits shows no dataStockTwits API is public but rate-limited; refresh will work next run. Some tickers have no StockTwits presence.
Add a ticker to custom watchlistEdit config/config.json → universe.custom_watchlist array
